# Nova Client (Minecraft 26.3, Fabric)

Installieren: `nova-client-1.0.0.jar` und die Fabric API (0.165.0+26.3) nach `%appdata%\.minecraft\mods`.
Fabric Loader für 26.3 und Java 25 werden gebraucht.

Im Spiel öffnet die **rechte Shift-Taste** das ClickGUI (änderbar unter Optionen > Steuerung). Esc schließt es.
